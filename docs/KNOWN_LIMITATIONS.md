# 已知限制与验证边界

这些是初始开源版本的现存边界。公开源码不是对所有网络、浏览器、文件规模或云资源策略的无限保证。

## 下载

- 兼容下载经过应用服务器，速度受其公网带宽限制，当前每个进程最多 8 个兼容流。
- 高级磁盘写入依赖浏览器 File System Access API；跨域 OSS 直下还需要正确的 CORS。缺少可核验 Range 头时使用固定地址回退。
- Range 下载支持单个字节范围，不提供 multipart/byteranges 响应。
- 网络持续不可用时，有限次数重试后会失败；原生浏览器下载管理器可以继续请求同一地址。恢复能力不代表所有浏览器会自动恢复。
- 永久保留由 `expires_at = NULL` 表示，但不能覆盖 OSS 生命周期、对象删除或管理员操作。
- 原项目曾验证 128 MiB 合成文件公网完整哈希；没有做 2 TiB 完整传输验收。`MAX_FILE_BYTES` 是业务上限，不是云厂商或已验证传输能力的承诺。

## 上传生命周期：待改进

- 清理器按任务创建时间判定 6 小时未完成，尚未完整利用 `last_seen_at`。超长活跃上传可能被错误清理。
- 上传完成前的 OSS HEAD 与取消状态更新存在竞态，应核对条件 UPDATE 的变化行数，并补齐幂等完成处理。
- 已取消 Multipart 的后台清理失败后，缺少完整持久化重试队列。
- 完成回执丢失后，重新选择同一文件可能建立重复上传。
- 删除中进程崩溃可能遗留 `DELETING` 状态，恢复流程有待完善。

## 公开版本的来源

来源于原工作区完整应用源码，保留前端、后端、测试、辅助脚本和设计/实施文档。本开源版本增加可重现安装、公共部署说明、CI 和发布内容扫描，并替换原生产资源默认值。它没有修改原工作区文件或部署到原线上服务，也不包含运行数据库、私有配置、验收日志中的分享凭证和无关下载资料。
